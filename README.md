# ML8 — Классификация риска покупки автомобиля

В этом проекте я решал задачу бинарной классификации: нужно было предсказать, окажется ли покупка подержанного автомобиля неудачной. Основной упор сделал на реализацию собственной нейронной сети и сравнение её результатов с готовыми решениями из Scikit-learn и PyTorch.

## Датасет

Для проекта использовался датасет из соревнования [Don't Get Kicked! на Kaggle](https://www.kaggle.com/competitions/DontGetKicked/data).

Целевая переменная — `IsBadBuy`:
- `0` — покупка не отмечена как неудачная;
- `1` — неудачная покупка.

В данных есть информация об автомобилях, их возрасте, марке, модели, характеристиках, стоимости и месте покупки.

Исходные данные не включены в репозиторий. Для запуска проекта нужно скачать файл `training.csv` и поместить его в папку `data`.

## Что было сделано

### 1. Подготовка данных

- Разделил данные на обучающую, валидационную и тестовую выборки с учётом даты покупки (`PurchDate`).
- Исключил из признаков идентификатор автомобиля и дату покупки.
- Разделил признаки на числовые и категориальные.
- Заполнил пропуски: медианой для числовых признаков и наиболее частым значением для категориальных.
- Масштабировал числовые признаки с помощью `MinMaxScaler`.
- Преобразовал категориальные признаки с помощью `CountEncoder`.

Разделение по времени позволяет проверять модель на более поздних данных, а не случайным образом перемешивать все наблюдения.

### 2. Реализация собственной нейронной сети

Написал класс `MLP` на NumPy без использования готовых реализаций нейронных сетей.

В модели реализованы:
- прямое распространение сигнала (forward pass);
- обратное распространение ошибки (backpropagation);
- бинарная кросс-энтропия (Binary Cross-Entropy);
- обновление весов с помощью SGD и Adam;
- мини-батчевое обучение;
- получение вероятностей классов и предсказаний.

Также добавил возможность выбирать функцию активации скрытого слоя: `tanh`, `arctan`, `ReLU`, `sigmoid` и `cosine`.

### 3. Сравнение с Scikit-learn

Обучил `MLPClassifier` с одним скрытым слоем из 64 нейронов, функцией активации ReLU и оптимизатором Adam.

Сравнение помогло оценить собственную реализацию и увидеть, как инициализация весов и особенности обучения влияют на результат.

### 4. Эксперименты с функциями активации

Сравнил ReLU, sigmoid и cosine в собственной реализации MLP.

В проведённом эксперименте лучший результат среди этих трёх вариантов показала функция `cosine`. Это наблюдение относится к конкретной конфигурации модели и не означает, что она всегда лучше других функций активации.

### 5. Реализация нейронной сети на PyTorch

Обучил аналогичную сеть с помощью PyTorch:
- входной слой;
- скрытый слой из 64 нейронов с ReLU;
- выходной слой с sigmoid;
- функция потерь `BCELoss`;
- оптимизатор Adam.

Использовал `DataLoader` для обучения мини-батчами и сравнил Gini на обучающей, валидационной и тестовой выборках.

## Результаты

Основная метрика проекта — **Gini**, вычисляемая через ROC-AUC:

\[
Gini = 2 \cdot ROC\text{-}AUC - 1
\]

Чем выше значение Gini, тем лучше модель различает неудачные и обычные покупки.

### Сравнение моделей

| Модель | Выборка | Gini |
|---|---|---:|
| Собственная MLP на NumPy (ReLU) | Валидационная | 0.3278 |
| Scikit-learn `MLPClassifier` | Валидационная | 0.3542 |
| Собственная MLP с cosine | Валидационная | 0.3508 |
| PyTorch MLP | Обучающая | 0.4413 |
| PyTorch MLP | Валидационная | 0.3644 |
| PyTorch MLP | Тестовая | 0.3645 |

Лучший результат на валидационной выборке показала модель на PyTorch. Её Gini составил 0.3644, а на тестовой выборке — 0.3645.

Разница между валидационным и тестовым результатами практически отсутствует. При этом Gini на обучающей выборке выше — 0.4413, поэтому полностью исключать переобучение только по этим значениям нельзя.
